# Internal URLs
Most FS/bash tools resolve these; path selectors: `read` docs.
- `agent://<id>`: latest completed output (status + progress while unpublished); nested IDs dotted, `/key/index` JSON path; write = message, `agent://all` broadcast only.
- `history://<id>`: read-only transcript; bare lists registered agents, not persisted unregistered top-level sessions.
- `artifact://<id>`: spilled output; page :N-M or :raw:N-M.
- `local://<name>.md`: shared artifact.
- `proc://`: jobs, agents, and services; `proc://<id>` status/output; write sends stdin to services only (empty = Enter); `proc://<id>/kill` cancels/stops jobs, agents, and services, omit `content`; `proc://<id>/mode`: `persist`|`session`|`detached` (services only); start long-lived work as a named service when it needs stdin or lifetime controls; `proc://<id>/streams` lists a bash job's pipes, `proc://<id>/streams/<n>` reads what crossed pipe `n` so far (live under `| tail`/`| grep`; never rerun to see it).
- `ssh://host/<path>`: remote UTF-8 file/dir (max 1 MiB) for read/write/grep; bare lists hosts. `/~/path` and `/~` use the connected remote account's HOME, not local HOME; `/~user` is unsupported, `/%7E/` is literal. Encode `:` `?` `#` as %3A %3F %23. Needs verified POSIX shell; else bash remote SSH or sshfs.
- `issue://<N>` / `pr://<N>` (`<owner>/<repo>/<N>` for other repos): GitHub issue/PR; bare: recent; `?state=&limit=&author=&label=`. PR diff: `pr://<N>/diff` (files), `/diff/<i>`, `/diff/all`. `?at=<generation>` pins that cached snapshot.
- `mcp://<uri>`: MCP resource.
- `omp://`: harness docs, AVOID unless asked.

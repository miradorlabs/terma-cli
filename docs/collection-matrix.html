*8Cursor interactive CLI 2026.09.10-fd3934a: two turns, generation IDs, token snapshots and file/commit attribution live verified. Response and Stop snapshots must not be summed. Headless --print omits turn hooks in the tested versions; conversation billing works. IDE validation pending. Collection contract.
*9Standalone Cursor team API importer and conversation cost join are live verified; platform scheduling, storage and UI integration are pending. Included model value is not extra cash spend. Tier/seat and quota meanings still need dashboard comparison. Importer contract.
*10Subagents are hook evidence filed under the session a person can find, with the agent named. Claude Code and Codex report an in-session agent (agent_id, agent_type) on start, stop and everything its hooks produce; a Codex subagent is a spawned thread, and its start carries the rollout's spawn record (agent_parent_id, depth, nickname, path). Claude stops require a previously observed SubagentStart or Agent/Task response for the same session and agent, excluding internal helpers' orphan stops. Launch evidence expires 14 days after its latest refresh by a start or tool response; stops alone do not extend that window. Claude Code's Agent tool call adds terma.subagent.call: the subagent's model and, when the parent waited for it, how the run went (duration, tool use and stats, the context's final size) — an observation keyed on agent_id. It is not what the run spent: the response's usage is the subagent's last request only, so no token count is sent, and spend stays the native export's. OpenCode reports a child session with parent_session_id; Cursor's subagentStop is filed under the parent conversation and the subagent's own edits are folded into it. Claude lifecycle and tool responses live verified on 2.1.278 (21 Sep 2026). Internal summary stop noise confirmed in a live session on 25 Sep 2026; the 30-second summary path was source-checked in 2.1.282, and the launch-evidence filter is regression-tested. Codex and Cursor are source-read, OpenCode SDK verified. Cursor's subagentStart is a permission gate and is never wired. The task's description, prompt and reply are never read. Collection contract.
*11Antigravity CLI 1.2.4 (agy), print mode with the repository bound as a workspace: session start, write/replace attribution, commit trailer and PostInvocation/Stop observations live verified 2026-09-16. Hooks load only in a trusted workspace, and an agy started in an unregistered directory works in its default CLI project and loads no repository hooks. Payloads and transcripts carry no token counts; agy has no OTLP export; no subagent hook exists. Interactive agy and the IDE unverified. Collection contract.
*12Cursor tool calls come from the generic postToolUse / postToolUseFailure hooks: tool name, tool_use_id, duration and outcome, never arguments or output. Documented contract (hook reference, 2026-09-17), not yet live verified; the platform's terma-cli adapter does not map terma.tool.call yet. Cursor's permission gates and the shell/MCP after* hooks are never wired. Antigravity's unmatched PostToolUse hook reports every tool step the same way: tool name, outcome and agy's step index as the call id (step-<stepIdx>), placed in a turn terma names by where it began; no duration (agy reports none), never arguments. Live verified on agy 1.2.7, 2026-09-18. Collection contract. Claude Code, Codex and OpenCode report tool calls in their native export. Collection contract.

# Harness telemetry fields

Generated by `make compat` (test/e2e/compatgen) from the live suite's field census: every attribute key each harness build exported over OTLP while the suite drove it, on each surface (a log event, a span or its event, a metric, the resource), and what terma's relay does with it when a project withholds content. Last generated 2026-10-10. Do not edit by hand: the catalog is `docs/compat/fields.json`.

**safe** leaves whatever the policy · **prompt** / **tool content** leave only when the project collects them · **unclassified** is withheld when its value is text, and counted, until it is classified in `internal/relay` or an agent's capture rules.
